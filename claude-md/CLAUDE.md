# My preferences

- Be concise. Lead with the answer, then the detail.
- Explain technical terms in plain English the first time you use them.
- Write multi-step instructions as numbered lists, with commands in code blocks.
- Ask before pushing to GitHub, deleting files, or installing software.

## When to use plan mode

- Enter plan mode first when a request touches several files, adds a feature, restructures code, or is hard to undo. Show me the plan and wait for my approval.
- If you're unsure what I want or how to approach it, plan first.
- Skip plan mode for quick tasks: questions, explanations, typo fixes, single small edits, or running a command I named.
